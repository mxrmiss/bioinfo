================================================================================
MAGIC PLOTTING KIT (v2.5 最终版)
顶刊级转录组数据可视化工具箱
================================================================================

本工具箱包含 9 个标准化 R 脚本，专为生成符合 Nature/Science/Cell 审美标准的
科研图表而设计。涵盖了从质量控制、差异分析、功能富集到时间序列趋势的全流程。

所有脚本均具备：
1. 自动模板生成（输入检查）
2. 顶刊级排版（无衬线字体、标准配色）
3. 工程化管理（自动归档输出）

================================================================================
1. 目录结构 (Directory Structure)
================================================================================

请务必保持以下目录结构，不要随意移动脚本位置：

magic/
├── input/          # [用户操作] 把您的 .tsv 数据文件都扔到这里
├── output/         # [自动生成] 脚本运行后，结果图会自动保存在这里
├── scripts/        # [核心代码] 存放 9 个 .R 脚本 (请勿修改内部逻辑)
├── templates/      # [自动生成] 存放标准表头模板 (供参考)
├── README_CN.txt   # 本说明文档 (中文)
└── README_EN.txt   # 说明文档 (英文)

2. 快速开始 (Quick Start)
================================================================================

第 1 步：环境安装 (仅需运行一次)
--------------------------------
在终端中运行：
$ Rscript scripts/install_env.R

第 2 步：准备数据
--------------------------------
将您的分析结果（如 gene_tpm.tsv, DEG_all.tsv, samples.tsv）放入 input/ 文件夹。
如果不知道表头怎么写，运行任意脚本一次，去 templates/ 文件夹看示例。

第 3 步：运行脚本 (⚠️ 核心铁律)
--------------------------------
必须在 magic/ 根目录下运行！严禁进入 scripts/ 目录运行。

[正确] $ Rscript scripts/pca.R
[错误] $ cd scripts; Rscript pca.R

3. 脚本功能详解 (The Magic 9)
================================================================================

--- 组别 A: 质量控制与概览 ---

1. pca.R (主成分分析)
   - [功能] 绘制 2D 和 3D PCA 图。
   - [输入] gene_tpm.tsv (表达矩阵), samples.tsv (分组信息)。
   - [亮点] 2D图带Biplot箭头和置信凸包；3D图为悬浮立方体风格。
   - [配置] 可在脚本头部修改 SHOW_ARROWS (显示箭头) 或 SHOW_ELLIPSE (显示凸包)。

2. global_heatmap.R (全局热图)
   - [功能] 绘制方差最大的 Top 2000 基因聚类热图。
   - [输入] gene_tpm.tsv, samples.tsv。
   - [用途] 放在附录 (Supplementary)，证明样本重复性好，无离群值。

--- 组别 B: 差异表达分析 ---

3. volcano.R (火山图)
   - [功能] 展示差异基因分布。
   - [输入] 差异分析表 (需包含 gene_id, log2fc, p_adjust)。
   - [亮点] 双向渐变色 (越显著越深)，混合加权标注 (P值+倍数)，X轴强制对称。
   - [配置] 可修改 P_CUTOFF (默认0.05) 和 FC_CUTOFF (默认1.0)。

4. venn.R (韦恩图/UpSet图)
   - [功能] 展示多组差异基因的交集。
   - [输入] 多个差异分析表 (脚本会自动扫描 input/ 下所有符合格式的表)。
   - [亮点] <5组画韦恩图 (小清新配色)，>4组自动切为 UpSet 图。自动输出交集基因列表。

--- 组别 C: 功能富集 (讲故事) ---

5. enrichment_bubble.R (富集气泡图)
   - [功能] 绘制 GO/KEGG 富集结果。
   - [输入] 富集结果表 (需包含 term_name, gene_ratio, p_adjust, gene_count)。
   - [亮点] S型顺滑排序，动态宽度锁定，单图/分面图自动切换。

6. enrichment_bar.R (富集柱状图)
   - [功能] 绘制富集排名的柱状图。
   - [亮点] 倒金字塔排序，-log10(P) 长度映射，与气泡图视觉完全对齐。

7. heatmap_term.R (通路特写热图)
   - [功能] 绘制特定通路 (Term) 下的核心基因热图。
   - [输入] 富集表 + gene_tpm.tsv + samples.tsv。
   - [亮点] 用法灵活！既可以画 Top 10 通路，也可以在脚本中指定 TARGET_TERMS 只画某一条通路。
   - [用途] 配合 K-means 趋势图，作为微观证据 (Evidence)。

--- 组别 D: 时间序列趋势 ---

8. kmeans_trend.R (趋势聚类图)
   - [功能] 将基因按表达趋势聚类 (如: 持续上升、先升后降)。
   - [输入] gene_tpm.tsv + samples.tsv + 多个差异表 (取并集)。
   - [亮点] 自动 Z-score 标准化，输出 Cluster 基因列表供后续分析。
   - [注意] 务必在脚本中修改 TIME_ORDER <- c("D0", "D1"...) 以匹配您的实验设计。

4. 常见问题 (FAQ)
================================================================================

Q: 报错 "Invalid Headers"？
A: 请检查 magic/templates/ 下生成的模板文件，您的输入文件表头必须严格匹配（区分大小写）。

Q: 报错 "failed to load cairo DLL"？
A: 您的 Linux 服务器缺少绘图库。请联系管理员运行：
   sudo apt-get install libcairo2-dev (Ubuntu)
   sudo yum install cairo-devel (CentOS)

Q: 3D PCA 图不能动？
A: 是的，这是用于发表的静态 PDF 矢量图。如果需要交互式网页图，请使用 Plotly (需改用 Python)。
